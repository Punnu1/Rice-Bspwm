# Rice-Bspwm
Contains three themes for bspwm

Requirements 
-
* BSPWM (duh)
* Feh
* Picom
* Rofi
* Polybar
* Dunst
* Python3 (needed for some modules)
* Bash compatible shell
(most of my scripts are for bash so convert them if youwant to use them in another shell)
  
INSTRUCTIONS
-
(I AM NEW TO THIS SO I WAS NOT ABLE TO MAKE A THEME SWITCHER SO YOU HAVE TO SWITCH THEMES MANUALLY BY TWEAKING THE RESPECTIVE SCRIPTS THAT YOU CAN SEE IN bspwmrc AND FOR MOST OF THE TIME YOU JUST HAVE TO CHANGE THE THEME NAME IN SCRIPTS OR COMMENT AND UNCOMMENT SOME LINE WHICH YOU CAN CLEARLY SEE)
